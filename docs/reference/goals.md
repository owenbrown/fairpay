# Objective
Retailers overbill poor people. Specifically, price tags in retailers that serve low-income households often display a price that is lower than one is charged at the register.
See https://www.theguardian.com/us-news/2025/dec/03/customers-pay-more-rising-dollar-store-costs

This is wrong. This application stops this abuse. 

The app is a web that allows users to take pictures of price tags, and then take a picture of their receipt, and know if they were overbilled.

# Project structure
The app is designed primarily so that a single developer can effectively leverage AI to develop quickly. As such, all features are carefully documents. 
Most documentation is found in the docs/ folder.

Work starts as a "project" in the projects folder. When in is completed, the document is moved to the "reference" folder.

The "docs/adr" folder descibes decisions about how the application is structured. The reasoning behind the decision is retained because it aids understanding. Start in this folder to understand the application.
